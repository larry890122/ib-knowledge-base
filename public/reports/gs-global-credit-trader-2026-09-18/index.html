2026-09-18US IGUS HYEUR IGEUR HY

重點摘要

GS將2027年全球direct hyperscaler IG gross debt issuance預估由約$400Bn上調至$420Bn，假設35%的CapEx以債務融資；其中65%–75%預期在USD IG市場發行。該數字不含data center與chip project finance，後者2027年另估$300Bn。2026年direct hyperscaler發行預估為$250Bn，年初至今已達$229Bn；全球AI相關gross debt issuance則達$578Bn，其中Hyperscaler僅占40%。AI相關債券已占美元投資級債與高收益債指數名目本金的12%及6%，歐元市場則為3%及1%，GS預期多年發行週期將使歐元市場承擔更多供給。GS認為非AI USD IG的韌性來自穩健經濟、信用基本面、all-in yield需求，以及Banks、Energy與Healthcare的分散效果；但仍對AI相關信用維持審慎，尤其Hardware較難隔離於compute shipment與融資壓力，project finance亦須逐案underwrite。其Q4 Spread forecast為USD IG 82bps、USD HY 295bps、EUR IG 88bps及EUR HY 315bps，均較目前略寬；全年gross supply則預估美元投資級債$2.3Tn、高收益債$400Bn、歐元投資級債€850Bn及高收益債€125Bn。配置上略偏好USD勝過EUR、BBB勝過高評等IG；USD HY偏好B、EUR HY偏好BB，兩地均Underweight CCC，並偏好HY bond、CLO mezzanine、Agency MBS及hybrid的相對價值。GS也預期四個市場的違約率仍將上升，因此相對價值配置不能取代個別信用選擇。

主題整理

2027年Hyperscaler direct issuance預估升至$420Bn

  • 預估較7月上調$20Bn： GS依最新CapEx forecast重新計算，假設2027年Hyperscaler CapEx有35%以債務融資，對應全球direct IG gross issuance約$420Bn。
  • 2027年發行量將較2026年增加逾60%： 2026年全年預估為$250Bn，年初至今已發行$229Bn；GS預期2027年發行明顯加速。
  • USD IG將吸收主要供給： GS預期2027年Hyperscaler gross issuance的65%–75%在USD IG市場完成，但實際比例取決於市場條件、投資人接受度及發行人集中度。
  • project finance須另行計算： $420Bn不含data center與chip project finance，GS對後者2027年的獨立預估為$300Bn。

全球AI相關融資遠超Hyperscaler本身

  • 年初至今AI相關gross issuance為$578Bn： 其中全球IG約$490Bn、leveraged finance約$88Bn；Hyperscaler只占總額約40%，其餘來自project finance及廣泛AI相關企業。
  • AI-adjacent Sector採保守歸因： 對Energy & Utilities、Oil & Gas、Machinery、Chemicals及Metal & Steel，GS僅將gross issuance的30%列為AI相關，且排除未動用credit facility與revolver。
  • EUR市場預期承擔更多融資： 目前非美元IG市場除EUR外規模有限，GS因此預期未來EUR IG與HY吸收的AI相關供給占比上升，convertible bond亦將扮演更大角色。

AI曝險在USD信用指數中持續提高

  • USD市場集中度最高： AI相關債券已占USD IG notional約12%、USD HY約6%；EUR IG與HY則分別約3%及1%。
  • 多年發行週期將進一步推高占比： GS認為Hyperscaler及project finance仍處於多年build-out，相關指數權重有明顯成長空間。
  • 今年多數Hyperscaler融資已完成但上行風險仍在： 近期供給壓力可能暫緩，但若市場情緒穩定，發行人反而可能加速融資，因此GS仍不主張大幅增加曝險。

非AI USD IG的韌性來自基本面與分散效果

  • 總體與信用環境仍具支撐： GS將非AI USD IG的相對韌性歸因於經濟活動穩健、信用基本面具建設性，以及all-in yield持續吸引收益型投資人。
  • 大型非AI Sector提供分散： Banks、Energy與Healthcare等較不直接受AI題材影響的Sector，可降低整體USD IG市場對單一融資主題的敏感度。
  • AI內部表現高度分化： Hyperscaler Spread近期局部回穩，但Hardware、Software與project finance面臨的風險不同，不宜以統一AI beta處理。

Hardware與project finance仍須審慎

  • Hardware較難隔離信用壓力： GS認為，隨compute shipment及其相關融資增長，Hardware發行人較難不受技術面與基本面壓力影響。
  • project finance供給可見度較低： Data center及compute project finance的發行時間與規模較難估計，但GS認為融資仍將持續推進。
  • 專案風險須逐案underwrite： 投資人應評估建設、租戶、合約與融資結構，因相關市場的供給技術面短期內不太可能消失。

Q4 Spread forecast仍指向高於目前水準

  • USD市場Q4 forecast： GS預估2026年Q4 USD IG Spread為82bps、USD HY為295bps，相較目前76bps及269bps均較寬；2027年Q2預估分別回到78bps與280bps。
  • EUR市場Q4 forecast： EUR IG及HY Spread預估分別為88bps及315bps，相較目前83bps與292bps較寬；2027年Q2預估為84bps及305bps。
  • 全年excess return forecast偏低： 2026年USD IG、USD HY、EUR IG及EUR HY excess return forecast分別為0.5%、1.3%、0.6%及1.4%。

2026年公司債供給與違約forecast

  • USD gross supply forecast： GS預估USD IG全年gross issuance為$2.3Tn、HY為$400Bn；net issuance則分別為$1.0Tn及$160Bn。
  • EUR gross supply forecast： EUR IG全年gross issuance為€850Bn、HY為€125Bn；net issuance分別為€265Bn及€60Bn。
  • 違約率仍將上升： GS預估2026年底USD HY與Leveraged Loan issuer-weighted LTM default rate分別為4.0%及4.75%，EUR HY與Loan則為5.0%及4.0%。

區域與評等配置偏好下移但避開CCC

  • 略偏好USD相對EUR： GS認為Euro Area的成長、通膨與貨幣政策組合較具挑戰，但跨境發行增加使區域界線逐漸模糊。
  • USD IG偏好BBB： GS偏好BBB勝過A及AA，以取得額外Spread，並認為最高評等公司也可能出現資產負債表惡化。
  • USD HY偏好B： AI相關供給使BB技術面較具挑戰，因此GS Overweight B、Neutral BB、Underweight CCC。
  • EUR IG與HY提高品質選擇： EUR IG偏好BBB勝過AA及A；EUR HY則Overweight BB、Neutral B、Underweight CCC。
  • IG相對HY轉為Neutral： 估值、rate sensitivity與供給技術面使GS不再認為全面Overweight IG的理由足夠明確。

Securitized與capital-structure相對價值仍具吸引力

  • 偏好HY bond勝過Loan： 美國與歐洲Loan市場均有較高Software曝險，且2028年再融資能見度有限；GS因此偏好HY bond。
  • 偏好CLO mezzanine勝過Leveraged Loan： BB及BBB CLO tranche歷史impairment率低，carry可對中度至偏高違約提供緩衝；senior CLO相對USD IG維持Neutral。
  • 偏好Agency MBS勝過IG corporate： GS認為Agency MBS可為IG公司債組合提供有吸引力的分散效果。
  • Overweight hybrid相對BBB： 在整體Spread偏tight的環境下，hybrid的額外補償仍屬中度吸引，且GS預期隨市場擴大，hybrid premium可相對BBB compression。
