每週信用市場摘要

2026-09-18

每週信用市場券商報告摘要及市場想法｜2026/09/18

本週重點

  • US IG： TD預期年末前US IG Spread由約76bps走向90-100bps，主因是AI與M&A帶來的供給壓力；BofA則將2026 hyperscaler供給上調至$330Bn，但認為2027年將下降20%，同時較高coupon與到期現金流可緩衝供給。（TD、BofA、Barclays、JPM）
  • EU： JPM偏好5年期EUR IG，以兼顧carry與潛在曲線走平下的duration風險；初級市場訂單仍健康，但hyperscaler供給和零售申購贖回轉弱是後續技術面風險。（JPM）
  • HY： JPM將2026年底US HY及Leveraged Loan Spread target分別下調至315bps與475bps，全年total return forecast為4%及6%；BofA的Loan CSI仍顯示Loans承受較HY更多邊際壓力，GS與Barclays則以品質、產業及資本結構選擇取代全面增加beta。（BofA、Barclays、GS、JPM）

1. US IG

1. 利差觀點

  1. 年末前利差偏寬但非衰退交易： TD預期US IG由約76bps進入90-100bps區間，主要反映供給壓力令利差相對模型公允值偏寬，而不是經濟立即轉弱。（TD）
  2. 高殖利率與基本面仍抑制失序式widening： Barclays認為核心企業資產負債表仍可承受較高利息負擔；JPM則認為零售資金雖會受total return影響，但反彈時仍能重新流入。（Barclays、JPM）
  3. 前端curve與較高coupon提供承接緩衝： BofA認為較hawkish的Fed令US IG 5s10s Spread curve走陡，較高殖利率與避險後收益有助前端需求；2027年到期與coupon付款估計較2026年增加$150Bn。（BofA）
  4. GS的Q4 forecast僅溫和高於現況： GS預估2026年Q4 USD IG Spread為82bps，相較報告時76bps略寬，並預期2027年Q2回到78bps。（GS）

2. 技術面

  1. AI與M&A將供給風險延後至旺季： TD維持2026年US IG gross supply $2.2Tn預估，認為9月初偏淡不改變10至11月發行增加的判斷。（TD）
  2. Hyperscaler與資料中心仍有年末融資空間： JPM預估2026年hyperscaler gross issuance為$230Bn、資料中心為$85Bn；截至報告日分別已發行$182Bn與$42Bn，後續發行時點會影響承接。（JPM）
  3. 短期供給與再投資現金流仍偏正面： BofA預估9月21日至25日US IG supply為$50-55Bn；9月14日當週約$41Bn到期與$21Bn coupon payments，使IG index現金較當週供給高約$17Bn。（BofA）
  4. 需求結構由國內買方支撐、海外買盤呈區域分化： TD預期IG funds/ETFs、保險與pension需求受高殖利率支持，並認為日圓避險後相對價值轉差可能削弱外資；JPM的FAB指標則顯示TWD與JPY相對價值月內改善、EUR與GBP轉弱，說明外資不能視為單一需求來源。（TD、JPM）
  5. 再投資現金的單週支撐將明顯下降： JPM指出本週$54Bn gross issuance低於$73Bn到期與coupon收入，但下週reinvestment income估計只有$24Bn，較9月週均低40%，初級市場承接將更依賴fund、insurance與海外買方。（JPM）
  6. 全年供給forecast普遍維持高檔： TD預估2026年US IG gross supply為$2.2Tn，GS為$2.3Tn；BofA則預估下週供給$50–55Bn，顯示年度高供給與短期現金緩衝可同時存在。（BofA、GS、TD）

3. 相對價值

  1. 曲線前端優於長端： TD最強conviction為US IG Spread curve走陡，前端受收益導向買盤支撐，長端則面臨AI與M&A相關的duration-heavy供給。（TD）
  2. 產業與評等選擇取代指數beta： GS偏好USD IG BBB勝過A/AA；TD偏好Utilities、Consumer Non-Cyclicals與Life Insurance，並對AI相關Tech維持較輕曝險。（GS、TD）
  3. Hybrid需要以結構與母公司信用挑選： JPM指出美元non-financial hybrid供給年初至今約$38Bn，主要由公用事業與通訊業推動，次順位與市場容量令個券研究更重要。（JPM）
  4. BBB壓縮接近歷史極端但BBB-仍有區隔： Barclays指出BBB/A Spread ratio在多數期限接近近10年低檔，惟排除AI後BBB-/BBB ratio仍高於歷史中位數；Banking、REIT與長天期Energy偏貴，Finance Companies與Transportation仍提供較多補償。（Barclays）
  5. CLO與Agency MBS提供公司債以外的carry： GS偏好CLO mezzanine勝過leveraged loans，並認為Agency MBS可分散IG corporate曝險；senior CLO與USD IG則維持中性，等待Spread widen後增加CLO部位。（GS）

4. 其他值得關注的議題

  1. AI融資規模仍持續上修： GS將2027年全球direct hyperscaler gross debt issuance預估上調至$420Bn，並另估約$300Bn資料中心project finance，顯示公開債以外的融資亦需納入供給評估。（GS）
  2. 2027年hyperscaler供給可能較今年正常化： BofA TMT analyst將2026年hyperscaler供給預估為$330Bn，並預期2027年減少20%；此判斷降低相同規模供給衝擊連續發生的機率，但不代表個別發行時點的壓力消失。（BofA）
  3. 資料中心個券分化仍大： Barclays認為IG資料中心在供給暫歇後回穩，但HY資料中心受較弱發行人與特定信用事件影響而持續落後。（Barclays）
  4. Active bond ETF形成結構性需求但流動性效果仍有限： Barclays估計全球fixed income ETF資產達$3.8Tn，其中active策略逾$700Bn；active fixed income ETF雖占資產20%，僅占交易量8%，目前對Cash Bond流動性的外溢仍低於passive ETF。（Barclays）
  5. Corporate supply不足以單獨主導全球殖利率： JPM估計全球Tech net bond issuance較2025年增加約$260Bn，對Global Agg yield的影響約10至15bps，計入政策利率預期後約5至10bps，Treasury仍是較大的duration impulse。（JPM）

2. EU

1. 利差觀點

  1. 5年期EUR IG為較佳的風險平衡點： JPM偏好5年期IG，認為潛在曲線走平下可降低duration風險，同時保留現有殖利率的carry。（JPM）
  2. 高殖利率提供緩衝但不消除升息歷史風險： EUR IG殖利率約4.3%，JPM的12個月簡化breakeven約為5.3%；過去ECB升息循環前後的平均走寬經驗仍支持審慎配置。（JPM）
  3. GS預期Q4 Spread溫和widen： GS預估2026年Q4 EUR IG及EUR HY Spread分別為88bps及315bps，相較報告時83bps與292bps較寬。（GS）

2. 技術面

  1. 初級市場承接健康但需面對hyperscaler供給： JPM觀察new-issue premium約10bps、訂單覆蓋約2.9倍，但預期未來數月較重的hyperscaler供給可能重新造成利差壓力。（JPM）
  2. 零售申購贖回轉弱： EUR IG與EUR HY分別約有€271Mn及€348Mn流出，與仍健康的機構新券訂單形成差異，後續需觀察是否擴大。（JPM）
  3. EUR IG當週供給活躍： 約22家發行人完成€21Bn交易，約一半來自Financials；new-issue premium約10bps、book coverage約2.9倍，顯示市場仍能運作，但不是零成本吸收供給。（JPM）
  4. 全年gross supply target仍高： JPM預估2026年EUR IG及EUR HY gross supply為€730Bn與€140Bn；GS則預估€850Bn與€125Bn，兩家對IG供給規模的判斷差異較大。（GS、JPM）

3. 相對價值

  1. EUR市場同樣偏好評等選擇： GS在EUR IG偏好BBB、在EUR HY偏好BB，對CCC維持低配，顯示供給環境下以品質控制風險。（GS）
  2. 房地產走弱反映產業敏感度： JPM指出Real Estate月內走寬約14bps，高於senior benchmark約8bps，支持以產業而非單純指數方式配置。（JPM）

4. 其他值得關注的議題

  1. EUR市場的AI融資壓力仍待觀察： GS認為AI相關融資的來源超出hyperscaler，資料中心project finance的規模與時點不確定，將影響歐洲與美元市場的共同投資人基礎。（GS）
  2. EUR將承接更高比例的AI融資： GS估計AI相關債券目前只占EUR IG與EUR HY notional約3%與1%，低於USD IG的12%與USD HY的6%；由於其他非美元IG市場規模有限，後續融資更可能增加EUR市場負擔。（GS）
  3. EUR hybrid的次順位補償仍具吸引力： JPM估計3至5年BBB-/BB+ hybrid相對senior約有100bps Spread pickup、sub/senior ratio約3至4倍，在整體Spread偏緊下仍有選券價值。（JPM）

3. HY

1. 利差觀點

  1. US HY利差與基金流同步轉弱： JPM記錄US HY Spread約303bps、基金流出$2.54Bn，說明高殖利率仍不足以完全抵銷利率與估值壓力。（JPM）
  2. 低品質信用仍需選擇性承擔： GS在USD HY偏好B、對CCC保持審慎；JPM亦看到B評等當週表現優於BB與CCC。（GS、JPM）
  3. CCC落後反映利率壓力尚未消散： BofA觀察HY Spread約270bps大致持平，但CCCs月內增加34bps，且HY total return當週約-0.65%，顯示低品質信用對較高利率更敏感。（BofA）
  4. JPM下調年底Spread target但維持風險平衡： JPM將US HY年底Spread target由350bps降至315bps、Leveraged Loan由525bps降至475bps，並將全年Loan total return forecast提高至6%，同時保留對地緣政治、Fed政策及估值的疑慮。（JPM）

2. 技術面

  1. 初級市場尚可運作： JPM指出當週有7筆、約$6.4Bn HY交易定價，顯示即使基金流出，具明確信用故事的新券仍可被吸收。（JPM）
  2. Loans相對具韌性： Leveraged loan價格約95.85並相對HY抗跌，但這不代表所有產業風險均已被消化。（JPM）
  3. HY內部需求下週將減弱： BofA指出本週到期與coupon帶來$7.4Bn內部需求，但下週僅約$1.8Bn；再融資占近期HY發行68%，使供給與再投資節奏更重要。（BofA）

3. 相對價值

  1. GS偏好HY bonds勝過loans： 在2028年前Software到期牆能見度有限下，GS認為HY bonds相對loans更具吸引力，同時維持對CCC的選擇性。（GS）
  2. Software是loan市場的主要例外： JPM追蹤Software loan Spread約735bps，顯著高於剔除Software後約429bps，說明風險集中於特定產業。（JPM）
  3. Loan CSI提示Loans較HY仍有更多壓力： BofA Loan CSI為49%、HY CSI為34%；以post-GFC歷史關係估算，Loan CSI對應未來三個月loan Spread約520bps，高於目前470bps，屬輕微走寬傾向。（BofA）
  4. Barclays偏好hybrid與有擔保結構： 在HY index高度壓縮下，Barclays偏好corporate hybrid勝過BB、non-software single-B loan勝過bond，並在同一資本結構中偏好secured bond，因unsecured-secured basis提供的補償有限。（Barclays）

4. 其他值得關注的議題

  1. HY基本面成長尚可但利息保障仍偏弱： JPM指出HY企業2Q營收及EBITDA年增仍強，但槓桿4.51x高於長期均值，interest coverage 4.12x低於長期均值。（JPM）
  2. 私募公司是基本面較脆弱的尾端： JPM資料顯示私募HY公司槓桿約5.62x、coverage約2.35x，均弱於公開公司，利率較高時需格外留意。（JPM）
  3. AI融資跨越HY、Loans與private credit： BofA統計美元AI相關融資年初至今達$549Bn，其中IG $259Bn、HY $40Bn、BSL $12Bn及private credit等$237Bn；AI HY信用相對非AI同類的Spread premium雖降至135bps，仍高於一般信用。（BofA）
  4. Private credit規模與近端到期牆同時上升： JPM估計invested direct lending market約$1.83Tn，另有約$302Bn institutional dry powder；private credit公司槓桿與coverage弱於公開HY，且到期較syndicated market前置。（JPM）
  5. Software顯著扭曲loan index： JPM指出loan index年初至今回報約3.68%，排除Software後約4.29%；Software Spread約735bps，遠高於排除Software後約429bps，顯示loan韌性不能直接外推至所有產業。（JPM）
